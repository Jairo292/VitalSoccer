# Kimi Agent Deployment

Este proyecto es un sitio estático generado con Vite y listo para servir desde la carpeta raíz.

## Cómo ejecutar

1. Abre una terminal en `Kimi_Agent_Deployment_v12/Kimi_Agent_Deployment_v12`
2. Ejecuta:

```bash
npm start
```

3. Abre en tu navegador:

```text
http://localhost:3000
```

## Nota

El proyecto debe ejecutarse desde un servidor HTTP local para que las rutas y los recursos se carguen correctamente.
